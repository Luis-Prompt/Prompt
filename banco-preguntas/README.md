# Banco de preguntas

Preguntas ya revisadas y aprobadas, guardadas en el mismo formato JSON que usa el generador de exámenes, para reutilizarlas y mejorarlas.

```
banco-preguntas/<area>/<grado>/<tema>.json
```

Cada pregunta debería llevar: `enunciado`, `pregunta`, `correcta`, `distractores`, `errores`, `justificacion` y, cuando exista, `competencia`, `nivel` y `dba`.
