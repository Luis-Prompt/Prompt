# Hojas de demostración

`hoja1.png` y `hoja2.png` son **figuras simples sintéticas** que imitan el formato que devuelve ChatGPT (2 filas × 4 columnas, fondo transparente). Sirven para probar el recorte con `examples/exam_con_imagenes.json`:

```bash
npm run ejemplo:imagenes
```

No son ilustraciones reales: para una prueba de verdad, genera las hojas con el prompt que entrega `--prompt-imagenes`.
