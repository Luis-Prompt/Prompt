# Plantilla para un prompt nuevo

1. Elige la categoría (`evaluacion`, `planeacion`… o crea otra) y copia esta carpeta: `cp -r prompts/_plantilla prompts/<categoria>/nombre-nuevo`.
2. Edita `SKILL.md` (corto y claro; el código va en `scripts/`).
3. Agrega un ejemplo funcional en `examples/`.
4. Crea `CHANGELOG.md` y `ROADMAP.md` (puedes copiar los del generador de exámenes).
5. Añade el prompt a la tabla del `README.md` principal.
