# Banco de imágenes

Recursos visuales reutilizables por todos los prompts.

```
banco-imagenes/
├─ escudos/        Escudos y logos institucionales (PNG, fondo blanco)
├─ plantillas-svg/ Gráficos reutilizables (figuras geométricas, mapas, esquemas)
└─ por-area/       matematicas/  ciencias/  lenguaje/  sociales/
```

Reglas: nombres sin tildes ni espacios (`recta_numerica_01.svg`); preferir **SVG** (se ve nítido al imprimir); no subir imágenes con derechos de autor ajenos ni fotos de estudiantes.
