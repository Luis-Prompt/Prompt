# Instrucciones para Claude

Este repositorio es una biblioteca de **prompts independientes** (pruebas tipo SABER y planeaciones de clase).

1. Lee [`INDICE-PARA-CLAUDE.md`](INDICE-PARA-CLAUDE.md), sección 0: dice qué hacer, en orden, cuando el docente te pasa este enlace.
2. El mapa completo con enlaces directos está en [`llms.txt`](llms.txt).
3. Elige UN prompt, prepáralo con `herramientas/preparar-prompt.sh` y sigue su `SKILL.md` desde el primer paso. No mezcles prompts.
4. Para desarrollar el repositorio: `npm test` (ver [`CONTRIBUTING.md`](CONTRIBUTING.md)).
